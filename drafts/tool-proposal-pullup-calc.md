対象記事: note「ECUフルコン化への道 抵抗1本でECUのプルアップ抵抗を逆算する方法」（2026-10-18公開、HP索引は `content/articles/note/misc-linkecu-8674a0.md`）
配置: `Tools` 配下の新規ページ `/tools/pullup/`（PWMシミュレータと同じ構成）
状況: フェーズ1の一部（タブA・B相当の①②、Raプリセット、入力チェック）を `/tools/pullup/` で公開済み。HP独自のまとめ記事（`pullup-resistor-from-voltage-and-resistance.md`）は、note記事と内容が重なるため取りやめた。

## 1. ツールの目的

記事の手順（既知抵抗 Ra を接続 → ECU入力電圧 V2 を測定 → R1 を逆算）を、電卓なしで計算できるようにする。
さらに、求めた R1 を使って「ECUが見ている電圧 V2 からセンサ抵抗 R2 を求める」ところまで同じページで完結させる。

## 2. 計算式（記事と同一）

| 計算 | 式 |
|---|---|
| プルアップ R1 を求める | `R1 = Ra × (Vin − V2) / V2` |
| センサ抵抗 R2 を求める | `R2 = R1 × V2 / (Vin − V2)` |
| 分圧（確認用） | `V2 = Vin × R2 / (R1 + R2)` |

検算値（記事の計算例）: Vin=5V, Ra=1000Ω, V2=1.5625V → R1=2200Ω（これを初期値にして、開いた瞬間に記事の例が再現される）

## 3. 画面構成（PWMシミュレータ踏襲：左に入力、右に結果・グラフ）

### 3-1. モード切替（タブ2つ）

**タブA「プルアップ抵抗 R1 を求める」（メイン）**

入力
- Vin（Ref電圧）[V] … 初期値 5.00。「テスターで実測した値を入れると精度が上がる」と注記
- Ra（接続した既知抵抗）[Ω] … 初期値 1000。単位は Ω / kΩ 切替。プリセットボタン `1kΩ` `2.2kΩ` `4.7kΩ`（記事の「試す抵抗」）
- V2（ECU入力電圧）[V] … 初期値 1.5625

結果
- **R1 = 2200 Ω（2.2 kΩ）** を大きく表示
- 近い標準値（E12 / E24）: `2.2kΩ` 。実測値との差 [%] も併記
- V2 の位置の判定バッジ
  - 2.0〜3.0V: 「良好（2.5V付近）」
  - 0.5〜2.0V / 3.0〜4.5V: 「可」
  - 0.5V未満 / 4.5V超: 「誤差大。Ra をもっとプルアップに近い値にしてください」
  - 0V以下 / Vin以上: 入力エラー（計算しない）
- 誤差の目安（最大誤差）: Ra が±1%、V2 測定が±0.01V の場合などを入力して R1 の誤差幅を表示（§5参照）

**タブB「センサ抵抗 R2 を求める」**

入力
- Vin
- R1（タブAの結果を引き継ぎ可。手入力も可）
- V2（ランタイム値の電圧）

結果
- R2 [Ω]
- （フェーズ2）温度換算：純正サーミスタのB定数 or 抵抗-温度表を貼り付けて温度表示

### 3-2. グラフ（右側）

- 横軸: センサ抵抗 R2 [Ω]（対数軸）、縦軸: V2 [V]
- 分圧カーブ `V2 = Vin × R2/(R1+R2)` を描画
- 現在の (R2 または Ra, V2) を点でプロット
- 2.5V の水平補助線と、「2.5V になるのは R2 = R1 のとき」という注釈
- 「Ra を変えたら V2 がどう動くか」が見えるので、記事の「抵抗の選び方」の説明をそのまま図で補強できる

### 3-3. 複数回測定の表（任意・フェーズ2）

- 行: 使った Ra（1kΩ / 2.2kΩ / 4.7kΩ …）と測定 V2
- 各行の R1 を自動計算し、平均とばらつき（最大-最小）を表示
- 「抵抗を変えても R1 がほぼ同じなら、測定が正しい」という確認に使える

## 4. 注意書き（ページ下部、記事の「測定時の注意」を転記）

- ECUの電源を入れた状態（5V供給状態）で測定する
- 抵抗値は事前に実測しておく（テスターで測った値を Ra に入れる）
- 入力ピンのショートに注意する
- 抵抗は1%品（秋月電子などの精度品）をおすすめ

ページ上部には記事へのリンク、`Tools` 一覧への戻りリンクを置く（PWMシミュレータと同じ）。

## 5. 誤差表示の考え方（目玉機能・実装は軽い）

R1 = Ra(Vin−V2)/V2 の相対誤差の最悪値は、

```
δR1/R1 ≈ δRa/Ra + δV2 × Vin / (V2 × (Vin − V2)) + δVin / (Vin − V2)
```

- V2=2.5V, Vin=5V, δV2=0.01V → 約0.8%
- V2=0.5V, Vin=5V, δV2=0.01V → 約2.2%
- 「V2 が 0V や 5V に近いほど誤差が増える」という記事の主張が数字で見える

入力欄: Ra の許容差（1% / 5% / 任意）、テスターの電圧分解能（0.001V / 0.01V 等）。結果に `R1 = 2200 Ω ±1.3%（2172〜2229 Ω）` のように表示。

## 6. 入力まわりの仕様

- 数値入力は半角/全角両対応、`2.2k` `2k2` `4.7K` のような表記も受け付ける（`2k2` は電子部品の慣習）
- 不正値は赤文字でその場にメッセージ、計算結果は「–」
- 結果は有効数字4〜5桁で丸め（PWMツールの `fmt` と同様）
- URLクエリ（`?vin=5&ra=1000&v2=1.5625`）で入力を共有できるようにする（記事から計算例へ直リンク可能）
