ECUの温度センサ入力には、多くの場合プルアップ抵抗が内蔵されています。この値が分からないと、センサの温度-抵抗特性が分かっていても、フルコンECUに正しい校正を入力できません。ここでは、**既知の抵抗と、そのとき測った電圧から、プルアップ抵抗値を逆算する方法**と、関連記事をまとめます。

このページは自分で書いた要約です。各noteの有料部分の内容は転載していません。

## 1. 基本の回路

ECU内部で、基準電圧 Vref（ほぼ5V）からプルアップ抵抗 R1 を通して入力ピンに接続されています。ピンの先にセンサ（サーミスタ）R2 がつながり、GNDに落ちています。

```
Vref (5V) ──[ R1 プルアップ ]──┬── ECU入力ピン (V2を測定)
                               │
                           [ R2 センサ ]
                               │
                              GND
```

ADC入力は高インピーダンスで、電流はほとんど流れないものとします。このとき分圧の式は次のとおりです。

```
V2 = Vref × R2 / (R1 + R2)
```

## 2. R1が分かっているとき: 電圧からR2を求める

式を変形すると、センサ抵抗が求まります。

```
R2 = R1 × V2 / (Vref − V2)
```

「温度センサの温度-抵抗特性とB定数」で紹介されているECU側の逆算式 `R2 = -R1-(5*R1)/(V2-5)` は、Vref=5V のときのこの式と同じです。計算は [プルアップ抵抗 逆算ツール](/kim23-lab-index/tools/pullup/) でもできます。

## 3. R1が分からないとき: 既知の抵抗でR1を求める

センサのコネクタ側から既知の抵抗（金属皮膜抵抗など）を入力ピンとGNDの間につなぎ、そのときの電圧を測ります。

### 3-1. 抵抗1本で求める（Vrefが5.00Vと見なせるとき）

```
R1 = R2 × (Vref − V) / V
```

### 3-2. 抵抗2本で求める（Vrefが不明でもよい）

抵抗 Ra と Rb をそれぞれ接続し、電圧 Va、Vb を測ります。

```
R1   = (Vb − Va) / (Va/Ra − Vb/Rb)
Vref = Va × (R1 + Ra) / Ra
```

Vrefが5Vちょうどでなくても求まります。2点の測定誤差の影響を受けるので、抵抗は2本とも、予想されるR1の0.3倍から3倍程度の範囲で、離れた値を選ぶと安定します。

### 計算例

Ra = 1kΩ、Rb = 10kΩ をつないで、Va = 1.5625V、Vb = 4.0984V を得たとします。

```
R1 = (4.0984 − 1.5625) / (1.5625/1000 − 4.0984/10000) = 2200 Ω
Vref = 1.5625 × (2200 + 1000) / 1000 = 5.0 V
```

## 4. 測定のコツ

- **抵抗は高精度のものを使います。** 1%以下の誤差のものを、テスターで実測してから使うと安心です。
- **電圧は高入力インピーダンスの計測器で測ります。** ECUのロギング値、またはテスターのDCV（入力インピーダンスが十分高いもの）を使います。
- **ECUの電源を入れた状態で、センサをつなぐピンだけを扱います。** 他のピンに触れたり、ショートさせたりしないように注意してください。
- **ピギーバック接続のときは並列になります。** 純正ECUのプルアップと、フルコン側のプルアップが両方つながる構成では、合成抵抗は `R1a × R1b / (R1a + R1b)` です。フルコン側のプルアップをOFFにできるかどうかを、先に確認してください。
- **同じ回路でも車種やセンサ（水温・吸気温・エバポレーター）ごとに値が違うことがあります。** 1つの値を、他の入力に流用しないでください。
- **抵抗値が分かったら** B定数やテーブルでセンサ特性を作り、ECUの校正に入力します。2点の温度と抵抗から、[サーミスタ B定数・温度-抵抗表ツール](/kim23-lab-index/tools/thermistor/)で -40〜160℃ の表（プルアップ抵抗を入れればECU入力電圧も）を作れます。
