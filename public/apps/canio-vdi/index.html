CAN I/O 仮想DI

このブラウザは Web Bluetooth に対応していません。
Android / PC は Chrome、iPhone は Bluefy などの Web Bluetooth 対応ブラウザで開いてください。 また、ページは https:// か localhost で開く必要があります。
● 未接続「接続」を押して CAN_IO_XIAO を選んでください

DI 設定 未保存の変更あり

Momentary：押している間だけ ON（bit7）／ Toggle：押すたびに ON/OFF（bit6）／ Accumulator：＋−で 0〜最大値（bit5〜0、最大 63）。
設定はこの端末のブラウザに保存されます（アプリの JSON と同じ形式で書き出し・読み込み可）。
LINK で読む位置：DIn は Byte(n−1)。Byte の先頭 bit の Start = Byte×8、Momentary は Start+0 / Toggle は Start+1（Width 1）、Accumulator は Start+2（Width 6）。
・送信：操作した瞬間＋変化がなくても 1 秒ごと（ハートビート）。モジュールは 2 秒届かないか BLE が切れると全 0 にします。
・画面を消したり別のアプリに切り替えると送信が止まり、2 秒後に全 0 になります（安全側）。使用中は画面を点けたままにしてください。
・CAN 出力：CAN_IO_XIAO は 0x6E2（PCUI で変更可）、CAN_GPS_LOGGER は 1023（0x3FF）。DI1 = Byte0 〜 DI8 = Byte7。
